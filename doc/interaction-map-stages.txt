GEOMETRY
────────
q   → curved rider (turn each step)
z   → zig-zag rider (alternate deltas)
g   → grasshopper hop ray
p   → cannon hurdle filter on slides
o   → cylindrical file wrap (or board wrapFiles/wrapRanks)
f/b/l/r/v/s/h → direction filter (square and hex)
U   → every other square on square/rect boards only

ANNOTATION
──────────
(board squares tagged empty / friendly / enemy)

PATH FILTERING
──────────────
n   → leap path must be clear (lame leaper)
j   → leap/slide must pass over ≥N occupied squares
p   → cannon: landing squares need exactly hopCount hurdles
g   → grasshopper: hurdle then landing beyond

CAPTURE LOGIC
─────────────
m   → empty destinations only
c   → enemy destinations only
e   → empty destinations that are en-passant targets (needs hook)
t   → skip royal enemy destinations (needs isRoyal hook)
i   → entire atom unavailable unless isVirgin hook is true

CONTINUATION
────────────
a   → another move leg; non-final legs default to move-only
p   → on a non-final leg, pass through to first blocker as platform

LANDING RULES
─────────────
m/c → combined m+c allows both empty and enemy
e   → empty landing must be en-passant target
t   → enemy landing rejected when isRoyal is true
